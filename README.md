# astrbot_plugin_gengwiki

让 [AstrBot](https://docs.astrbot.app/) 机器人用上[梗Wiki](https://gengwiki.niox.lol) 的中文网络热梗和表情包。

## 功能

- **人设**，用 Key 绑定的人设回复，可以填多个 Key，聊天时随时切换。
- **回复时用梗**，每次回复前给模型一批梗作为参考，用梗的频率可以在配置里选。
- **群里插话**，没人叫它时也可能接一句，只有想到非常贴切的梗才开口。
- **人物和语录**，模型认识 Key 关联的人物，语录怎么用、用得多不多可以在配置里选。
- **发表情**，模型按说明文字选表情直接发出，默认发多少听人设的，也可以在配置里选频率。
- **查询工具**，模型可以搜索梗和人物、查看详情和热门榜。查梗和发表情的步骤由插件告诉模型，人设里只要写性格和说话方式。

## 安装

需要 AstrBot 4.24 或更高版本，对话模型要支持工具调用，执行方式要用内置 AstrBot AI。

1. 在 AstrBot 的 WebUI 打开插件页，点右下角的 **+**，选择从 URL 安装，填入 `https://github.com/Niox1337/astrbot_plugin_gengwiki`。
2. 在[梗Wiki 个人中心](https://gengwiki.niox.lol/me)创建 API Key，勾选 `memes:read`、`trending:read`、`persona:read`、`stickers:read` 和 `people:read`，选择人设，并关联要用的梗、表情包和人物。一个 Key 只能绑定一个人设，想用几个人设就创建几个 Key。
3. 在插件配置的 `api_keys` 里填入 Key。

每个 AstrBot 用自己的 Key，不要和别人共用。

## 切换人设

| 指令 | 作用 |
|---|---|
| `/人设` | 列出可选人设 |
| `/人设 2` | 按序号切换 |
| `/人设 温柔姐姐` | 按名字切换 |

- 每个群和私聊分别记住自己的选择，重启后不变。没选过的会话用第一个 Key。
- 会话里的任何人都能切换。
- 切换时，这个会话能用的梗和表情包也会换成新 Key 关联的那些。
- 梗Wiki 人设排在 AstrBot 自己的人设后面，并声明优先。想用回 AstrBot 的人设，加一个没有绑定人设的 Key 并切换过去。
- 之前的对话记录不会清空，如果模型还带着之前的语气，发送 `/reset`。

## 语录

| 指令 | 作用 |
|---|---|
| `/语录` | 从这个 Key 关联的人物里随机发一句 |
| `/语录 鲁迅` | 发这个人物的一句，按名字或别名找 |

## 配置

| 配置项 | 含义 | 默认值 |
|---|---|---|
| `api_keys` | 梗Wiki API Key，可以填多个，第一个是默认人设 | 无 |
| `quote_mode` | 人物语录的用法，可选不使用、引用、直接使用、引用和使用 | 引用 |
| `quote_frequency` | 使用语录的频率，可选偶尔、有时、经常。Key 没有关联带语录的人物，或者 `quote_mode` 选不使用时无效 | 偶尔 |
| `sticker_frequency` | 发表情的频率，可选不发、跟随人设、偶尔、有时、经常 | 跟随人设 |
| `meme_frequency` | 主动玩梗的频率，可选不主动、偶尔、有时、经常 | 偶尔 |
| `join_chance_named` | 群友提到梗时插话的概率 | 0.5 |
| `join_chance_any` | 其他群消息插话的概率 | 0.02 |
| `join_cooldown` | 同一个群两次插话的最短间隔（秒） | 300 |

通过概率判定后会调用一次模型，哪怕最后没有开口。不想让它插话，把两个概率都设为 0。`meme_frequency` 选不主动时也不会插话。

三个频率只改变给模型的指令，不是精确的比例，实际多少还要看模型。偶尔只在非常贴切时才用，有时沾边就可以用，经常说得通就用，认真求助或倾诉时除外。

- 发表情选跟随人设时听人设的，选偶尔、有时、经常时优先于人设。
- 发表情选不发时，模型不会发表情，也不再带表情列表。
- 玩梗选不主动时，回复不带梗列表，模型被问到时仍然可以查梗。
- `/语录` 指令只看 `quote_mode`，不受频率影响。
