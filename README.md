# astrbot_plugin_gengwiki

让 [AstrBot](https://docs.astrbot.app/) 机器人用上[梗Wiki](https://gengwiki.niox.lol) 的中文网络热梗和表情包。

## 功能

- **人设**，用 Key 绑定的人设回复，可以填多个 Key，聊天时随时切换。
- **回复时用梗**，聊天时自然地用上合适的梗，频率可以在配置里调。
- **群里插话**，没人叫它时也可能接一句，只有想到非常贴切的梗才开口。
- **订阅标签**，除了 Key 绑定的梗，模型还会用上订阅标签里最热的梗。
- **人物和语录**，模型认识 Key 关联的人物，语录怎么用可以在配置里选。
- **发表情**，模型按说明文字选表情直接发出，发多少听人设的。
- **频率**，玩梗、用语录和发表情的多少都可以在配置里调。
- **查询工具**，模型可以搜索梗和人物、查看详情和热门榜。查梗和发表情的步骤由插件告诉模型，人设里只要写性格和说话方式。
- **直接指令**，`/梗`、`/热梗` 和 `/表情` 马上回答，不经过模型。
- **添加自己的**，聊天里用 `/添加梗` 添加自己的词、表情、人设和人物，只有自己的 Key 能用，不用审核。

## 安装

需要 AstrBot 4.24 或更高版本，对话模型要支持工具调用，执行方式要用内置 AstrBot AI。

1. 在 AstrBot 的 WebUI 打开插件广场，搜索梗Wiki 安装，也可以打开[它在插件广场的页面](https://cloud.astrbot.app/plugin/Niox1337/astrbot_plugin_gengwiki)。或者打开插件页，点右下角的 **+**，选择从 URL 安装，填入 `https://github.com/Niox1337/astrbot_plugin_gengwiki`。
2. 在[梗Wiki 个人中心](https://gengwiki.niox.lol/me)创建 API Key，勾选 `memes:read`、`trending:read`、`persona:read`、`stickers:read` 和 `people:read`，选择人设，并关联要用的梗、表情包和人物。一个 Key 只能绑定一个人设，想用几个人设就创建几个 Key。
3. 在插件配置的 `api_keys` 里填入 Key。

每个 AstrBot 用自己的 Key，不要和别人共用。

不填 Key 也能先用起来，只是只有梗Wiki 热门的 20 个梗和 10 个人物，没有人设和表情包。第一次回复时机器人会发一条提醒，告诉你去哪里创建 Key。不想这样，在配置里关掉 `guest_memes`，没有 Key 时就不玩梗，只发这条提醒。

## 查梗和发表情

这些指令马上回答，不经过模型，也不花 token。发送 `/梗帮助` 查看全部指令。

| 指令 | 作用 |
|---|---|
| `/梗 躺平` | 查一个梗的释义、使用场景和链接，顺带列出相关的梗 |
| `/热梗` | 全站最热的 10 个梗 |
| `/热梗 游戏` | 这个标签最热的梗 |
| `/表情 震惊` | 按说明文字发一张表情 |
| `/表情` | 随机发一张表情 |

- `/梗` 查的是 Key 关联的梗、当前会话订阅标签的热梗和全站热门榜，查不到时给出全站搜索和新建词条的链接。
- 表情第一次发送时下载到本地，之后不再下载，下载失败时发链接。
- `sticker_frequency` 设为 0 时 `/表情` 不可用。

## 切换人设

| 指令 | 作用 |
|---|---|
| `/人设` | 列出可选人设 |
| `/人设 2` | 按序号切换 |
| `/人设 温柔姐姐` | 按名字切换 |

- 每个群和私聊分别记住自己的选择，重启后不变。没选过的会话用第一个 Key。
- 会话里的任何人都能切换。
- 切换时，这个会话能用的梗和表情包也会换成新 Key 关联的那些。
- 梗Wiki 人设排在 AstrBot 自己的人设后面，并声明优先。想用回 AstrBot 的人设，加一个没有绑定人设的 Key 并切换过去。
- 之前的对话记录不会清空，如果模型还带着之前的语气，发送 `/reset`，在群里要 AstrBot 管理员才能发。

## 语录

| 指令 | 作用 |
|---|---|
| `/语录` | 从这个 Key 关联的人物里随机发一句 |
| `/语录 鲁迅` | 发这个人物的一句，按名字或别名找，找不到时提示相近的人物 |

## 订阅标签

| 指令 | 作用 |
|---|---|
| `/梗标签` | 查看全部标签和每个标签有多少梗 |
| `/梗订阅` | 查看当前会话订阅的标签 |
| `/梗订阅 游戏` | 订阅这个标签，模型也会用上它最热的 5 个梗 |
| `/梗退订 游戏` | 退订这个标签 |

- 订阅只对当前会话生效，会话里的任何人都能订阅和退订，换人设时订阅还在。
- 已经绑定在 Key 上的梗不会重复出现。
- 模型搜索时也能找到热门榜和当前会话订阅标签里的梗，这些梗只有释义和使用场景。
- Key 要勾选 `trending:read`。

## 主动插话

| 指令 | 作用 |
|---|---|
| `/梗插话` | 查看当前会话是开还是关 |
| `/梗插话 关` | 当前会话不再主动插话，被叫到时照常回答 |
| `/梗插话 开` | 重新打开 |

- 每个群分别记住，重启后不变，会话里的任何人都能切换。
- 模型决定不开口时，这次判断不会写进对话记录。

## 刷新数据

| 指令 | 作用 |
|---|---|
| `/梗刷新` | 马上重新读取人设、梗、表情和人物 |

- 插件会把数据存在本地，人设、梗列表、表情包和人物最多 6 小时自动更新一次，热门榜和标签 15 分钟，改动想马上生效时发送这个指令。
- 所有 Key 的数据都会刷新，会话里的任何人都能用。
- 连不上梗Wiki 时会提示，并继续用旧数据。

## 添加自己的

| 指令 | 作用 |
|---|---|
| `/添加梗 词 名字 解释` | 让机器人认识一个词，聊到它时模型就懂 |
| `/添加梗 表情 说明` | 消息里带一张图，或者回复一张图，用 `/表情 说明` 发出 |
| `/添加梗 人设 名字 提示词` | 添加一个人设 |
| `/添加梗 人物 名字 简介｜语录｜语录` | 添加一个人物，语录可以不写 |
| `/删除梗 词 名字` | 删除自己添加的，表情、人设和人物也一样 |

- 添加的内容只有自己的 Key 能用，不公开，也不用审核，在[我的组合](https://gengwiki.niox.lol/me)里能看到和修改。
- 会话里的任何人都能用。同名的会更新，不会重复添加。
- 表情会缩到边长 500 以内，动图已经够小时保持原样。
- Key 的人设创建后不能改，新的人设要在我的组合新建一个组合选它，再把新 Key 填进 `api_keys`。
- 没有配置 Key 时不能添加。

## 排查问题

| 指令 | 作用 |
|---|---|
| `/梗状态` | 查看当前 Key 的人设，有多少梗、表情、人物和语录，缺哪些权限，还有现在的频率、插话开关和订阅 |

插件启动时也会把每个 Key 的情况写进 AstrBot 日志，Key 填错了在这里能看到。

## 配置

| 配置项 | 含义 | 默认值 |
|---|---|---|
| `api_keys` | 梗Wiki API Key，可以填多个，第一个是默认人设 | 无 |
| `guest_memes` | 没有 Key 时也玩梗，关掉后只发一次提醒 | 开 |
| `quote_mode` | 人物语录的用法，可选不使用、引用、直接使用、引用和使用 | 引用和使用 |
| `meme_frequency` | 主动玩梗的频率，0 到 1 | 0.3 |
| `quote_frequency` | 使用语录的频率，0 到 1。Key 没有关联带语录的人物，或者 `quote_mode` 选不使用时无效 | 0.4 |
| `sticker_frequency` | 发表情的频率，0 到 1 | 0.3 |
| `join_chance_named` | 群友提到梗时插话的概率 | 0.8 |
| `join_chance_any` | 其他群消息插话的概率 | 0.01 |
| `join_cooldown` | 同一个群两次插话的最短间隔（秒） | 300 |

通过概率判定后会调用一次模型，模型觉得不贴切就不开口。不想让它插话，把两个概率都设为 0。`meme_frequency` 设为 0 时也不会插话。只想关掉某个群，在群里发送 `/梗插话 关`。

### 频率

三个频率都是 0 到 1 的数字，越大越常玩梗、用语录和发表情。这个数字是上限，模型还会看语境决定用不用、用哪个。

默认值用 DeepSeek 和两个人设测试过，一到两成的回复会玩梗，不到一成用语录，一到两成带表情，比例因模型和人设而异。认真求助或倾诉时一般不玩梗，偶尔也可能用得不太贴切，觉得太多就调低。

- `quote_mode` 选直接使用或引用和使用时，语境合适的回复整条只有一句语录原话，不加其他文字。玩梗和语录同时掷中时二选一。
- 消息里提到“表情”“斗图”“来张图”“发张图”时不受表情频率限制，提到“语录”“名言”“金句”时不受语录频率限制，只有设为 0 时例外。
- `meme_frequency` 设为 0 时，模型被问到时仍然可以查梗。`sticker_frequency` 设为 0 时不发表情。
- `/语录` 指令只看 `quote_mode`，不受频率影响。
- 群里插话由 `join_chance_named` 和 `join_chance_any` 决定，通过后模型只在梗贴切时才开口。
- 调低频率通常也能省一些 token。
